<objective>
Fix PropArbitrageAgent's mathematically incommensurable EV comparison: replace the h2h moneyline implied probability source (context_signals.odds_snapshot) with a player-prop-specific implied probability derived from a matched PlayerPropSnapshot row stored in GraphState.

Purpose: PROP-06 EV outputs are currently meaningless — a prop market probability (P(player_passes_over_250.5_yds)) divided against a game-winner moneyline probability produces a number that cannot be interpreted as edge. This fix makes both probabilities refer to the same prop outcome.

Output: Updated state.py (new field), agents.py (populate field in return dict), prop/arbitrage.py (new match path), and test_prop_arbitrage.py (Wave 0 tests + updated fixtures).
</objective>

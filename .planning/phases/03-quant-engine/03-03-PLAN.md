BacktestSignal input shape (to be defined in backtest.py):
```python
@dataclass
class BacktestSignal:
    quant_result: QuantResult        # signal's probability estimate
    closing_implied_prob: Decimal    # fair prob from closing line (post-devig via vig.py)
    actual_outcome: bool             # True = bet won
    stake: Decimal                   # notional stake (e.g. Decimal("100"))
    payout_multiplier: Decimal       # decimal odds payout (e.g. Decimal("1.909") for -110)
    game_start_time: datetime        # for closing line timestamp guard documentation
    snapshot_time: datetime          # must be < game_start_time (caller enforces, noted in docstring)
```

BacktestReport output shape (to be defined in backtest.py):
```python
@dataclass
class BacktestReport:
    roi: Optional[float]             # sum(profit) / sum(stake); None if sample_size == 0
    hit_rate: Optional[float]        # wins / total_bets; None if sample_size == 0
    clv_mean: Optional[float]        # mean(closing_implied_prob - signal_implied_prob); None if 0
    sample_size: int                 # len(signals)
    signals_df: Optional[pd.DataFrame]  # enriched DataFrame; None if sample_size == 0
```

BacktestEngine pattern from RESEARCH.md Pattern 6:
```python
class BacktestEngine:
    def run(self, signals: list[BacktestSignal]) -> BacktestReport:
        if not signals:
            return BacktestReport(roi=None, hit_rate=None, clv_mean=None, sample_size=0, signals_df=None)
        df = pd.DataFrame([...])  # convert signals to dicts
        df["signal_implied_prob"] = [float(s.quant_result.true_probability) for s in signals]
        df["raw_clv"] = df["closing_implied_prob"].astype(float) - df["signal_implied_prob"]
        df["profit"] = df.apply(lambda r: r["stake"] * (r["payout_multiplier"] - 1) if r["actual_outcome"] else -r["stake"], axis=1)
        ...
```

Pitfall 6 from RESEARCH.md: BacktestReport must include a metadata note that `snapshot_time < game_start_time` is the caller's responsibility — the module documents this constraint but does not enforce it (no DB access in BacktestEngine).

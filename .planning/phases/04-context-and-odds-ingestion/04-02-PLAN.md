Create src/sportsbet/ingestion/odds_poller.py with:

1. **Module constants:**
   ```python
   ODDS_API_BASE = "https://api.the-odds-api.com"
   NFL_SPORT_KEY = "americanfootball_nfl"
   DEFAULT_STALENESS_MINUTES = 5
   ```

2. **BudgetExhaustedError** — custom exception (inherits from RuntimeError):
   ```python
   class BudgetExhaustedError(RuntimeError):
       """Raised when Odds API daily credit cap is reached or credits_remaining < 1."""
   ```

3. **is_stale(snapped_at, threshold_minutes)** — standalone function:
   - Always use `datetime.now(timezone.utc)` (never `datetime.utcnow()`)
   - snapped_at MUST be timezone-aware; raises TypeError on naive input (caught by tests)
   - Returns bool: True if stale, False if fresh
   - Default threshold_minutes=DEFAULT_STALENESS_MINUTES

4. **OddsAPIPoller** — async context manager class:
   - `__init__(api_key: str, daily_credit_cap: int)`
   - `async __aenter__` → creates `httpx.AsyncClient(base_url=ODDS_API_BASE, timeout=10.0)`
   - `async __aexit__` → calls `await self._client.aclose()`
   - `async fetch_nfl_odds(regions="us", markets="h2h,spreads,totals") -> list[dict]`
     - Check `_credits_remaining`: if not None and < 1, raise BudgetExhaustedError immediately (no HTTP call)
     - Call `GET /v4/sports/{NFL_SPORT_KEY}/odds` with apiKey, regions, markets params
     - Call `response.raise_for_status()`
     - Read `x-requests-remaining` header; update `self._credits_remaining`
     - Return `response.json()`
   - `_credits_remaining: int | None = None` (None = first call, not yet read from server)

   Note on budget persistence: In v1, _credits_remaining is in-memory only. The Phase 4 RESEARCH.md open question #3 (persist across restarts) is deferred — log a WARNING on startup via structlog if _credits_remaining is None so operators know the counter reset.

<objective>
Build the NBA-specific query builder and executor for player prop probability estimation. This is the statistical engine for NBA props: NBAQueryBuilder constructs parameterized SQL against nba_player_stats, and run_nba_prop_query applies a NormalDist CDF model (season-aggregate data cannot use frequency counts like NFL).

Purpose: The nba_player_stats table stores season totals (one row per player per season from LeagueDashPlayerStats Totals mode). Probability must be derived via normal approximation: avg_per_game = total_stat / games_played, std = avg_per_game * CV_MAP[prop_type], true_probability = NormalDist(avg, std).cdf(line) with the result being P(stat < line) so P(OVER) = 1 - cdf(line).

Output: nba_query_builder.py, nba_executor.py, test files, and PropParams extended with "double_double".
</objective>

    Helper `_norm_cdf_over(avg: float, std: float, line: float) -> float`:
    ```python
    from statistics import NormalDist
    # P(stat > line) = 1 - P(stat <= line) = 1 - NormalDist(avg, std).cdf(line)
    return 1.0 - NormalDist(mu=avg, sigma=max(0.5, std)).cdf(line)
    ```
    The `max(0.5, std)` is the std floor that prevents StatisticsError when avg=0.

    Helper `_double_double_prob(avg_pts: float, avg_reb: float, avg_ast: float) -> float`:
    ```python
    # Inclusion-exclusion P(at least two categories >= 10)
    # Independence assumption — documented as v1 heuristic
    std_pts = max(0.5, avg_pts * float(NBA_PROP_CV_MAP["points"]))
    std_reb = max(0.5, avg_reb * float(NBA_PROP_CV_MAP["rebounds"]))
    std_ast = max(0.5, avg_ast * float(NBA_PROP_CV_MAP["assists"]))
    p_pts = _norm_cdf_over(avg_pts, std_pts, 10.0)
    p_reb = _norm_cdf_over(avg_reb, std_reb, 10.0)
    p_ast = _norm_cdf_over(avg_ast, std_ast, 10.0)
    return p_pts * p_reb + p_pts * p_ast + p_reb * p_ast - 2 * p_pts * p_reb * p_ast
    ```

    `async def run_nba_prop_query(pool: asyncpg.Pool, params: PropParams) -> PropResult`:
    1. sql, args = NBAQueryBuilder.build(params)
    2. async with pool.acquire() as conn: row = await conn.fetchrow(sql, *args)

    4. if total_games < MIN_SAMPLE_GAMES: return PropResult(data_source="insufficient_sample", sample_size=total_games)
    5. Handle double_double separately: extract avg_pts, avg_reb, avg_ast from row; call _double_double_prob; wrap as Decimal(str(round(p_dd, 6))); return PropResult(true_probability=..., sample_size=total_games, data_source="postgresql", mean_stat=None)
    6. For other prop types: avg_per_game = float(row["avg_per_game"] or 0.0); cv = NBA_PROP_CV_MAP[params.prop_type]; std = max(0.5, avg_per_game * float(cv)); p_over = _norm_cdf_over(avg_per_game, std, float(params.line)); true_prob = Decimal(str(round(p_over, 6))); mean_stat = Decimal(str(round(avg_per_game, 2)))
    7. Clamp: true_prob = max(Decimal("0.01"), min(Decimal("0.99"), true_prob))
    8. Return PropResult(true_probability=true_prob, sample_size=total_games, data_source="postgresql", mean_stat=mean_stat)
    Note: Wilson CI is NOT used here (not a proportion with known successes/total) — confidence_interval=None is acceptable; document in docstring.

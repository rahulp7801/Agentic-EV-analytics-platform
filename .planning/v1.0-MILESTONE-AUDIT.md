## Integration Gaps

### HIGH Severity

**INT-01: `create_graph_with_sqlite()` missing Phase 5/6 node wiring**
- Phase 5 (CorrelationGuard, Aggregator) and Phase 6 (kinematic agent) nodes are wired correctly in `create_graph()` but never passed through the production runtime factory `create_graph_with_sqlite()`.
- Any caller using the convenience factory runs with Phase 2 stubs for arbitrage and no real risk controls.
- Fix: add `arbitrage_node`, `correlation_guard_node`, `aggregator_node`, `kinematic_node` params to `create_graph_with_sqlite()`.

**INT-02: `receiver_gsis_id` not declared in `GraphState`**
- `make_kinematic_agent` reads `state.get("receiver_gsis_id", "")` but the field is absent from the `GraphState` TypedDict. All production kinematic queries silently use `""` as the receiver GSIS ID.
- Fix: add `receiver_gsis_id: str` (and optionally `week: int`) to `GraphState`.

**INT-04: Vig removal functions not connected to EV pipeline**
- `_extract_odds_snapshot()` converts American odds inline with plain division, preserving the bookmaker vig. `compute_ev_percentage` receives vig-inclusive `implied_probability`. `sportsbet.quant.vig` is never imported by any production code path.
- Fix: call `american_to_raw_prob` + `remove_vig_multiplicative` (or `remove_vig_power`) before constructing `AgentOddsSnapshot.implied_probability`.

### MEDIUM Severity

**INT-03: `avg_time_to_throw` missing from `_SEPARATION_QUERY`**
- The column is not in the SELECT list but `matchup.py` attempts `row.get("avg_time_to_throw")`. Result is always `None`.
- Fix: add `AVG(ngs_stats.avg_time_to_throw)` to the SELECT (requires JOIN to passing stat_type row for the QB in the same game).

**INT-05: `write_odds_snapshot()` never called — CLV tracking disconnected**
- Context agent converts live odds to in-memory `AgentOddsSnapshot` but never persists to `odds_snapshots` table.
- Fix: call `write_odds_snapshot()` inside `make_context_agent` after fetching and validating live odds.

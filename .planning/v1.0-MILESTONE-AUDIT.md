## Cross-Phase Integration Findings

### Critical Gaps

#### INT-1: situational_params → PropParams bridge missing

- **Location:** `src/sportsbet/graph/agents.py` line 351 (writer) vs `src/sportsbet/prop/agents.py` (reader — missing)
- **Issue:** `make_context_agent` injects `{"situational_params": {"teammate_out_signals": [player_name, ...]}}` into GraphState. `make_prop_quant_agent` reads only `receiver_gsis_id`, `season`, `game_id`, `prop_type`, `prop_line`, and `prop_filters` from state — never reads `situational_params`. `PropParams.teammate_out` is never populated from state. The conditional `teammate_out` WHERE clauses in `PropQueryBuilder.build()` and `NBAQueryBuilder.build()` are never triggered in automated runs.
- **Affected:** Phase 18 SC-3 and SC-4 end-to-end pipeline; PROP-03 / PROP-05 situational enhancement
- **Fix required:** `make_prop_quant_agent` must read `state.get("situational_params", {})` and forward `teammate_out_signals` → `PropParams.teammate_out`

#### INT-2: PlayerPropSnapshotCreate sport field hardcoded (PROP-01)

- **Location:** `src/sportsbet/graph/agents.py` line 304
- **Bug:** `PlayerPropSnapshotCreate(sport="nfl", ...)` — string literal instead of the `sport` variable resolved at line 219
- **Impact:** When `state["sport"]="nba"`, `fetch_player_props("nba")` fetches NBA prop data but every `PlayerPropSnapshotCreate` is written to `player_prop_snapshots` with `sport='nfl'`. NBA prop snapshot queries filtering by `sport='nba'` return no results.
- **Fix required:** Change `sport="nfl"` → `sport=sport` (1-line fix)

### Non-Critical Findings

#### INT-3: NBAContextSignals has no pipeline producer (NBA-02 / PROP-05)

- **Issue:** `GraphState.nba_context_signals` is documented as caller-supplied. No agent, scraper, or ingestion module auto-derives `pace_factor`, `opponent_def_rating`, `rest_days`, `is_home` from live data and injects them into GraphState. In automated pipeline runs, `state.get("nba_context_signals")` is always `None`. The four-stage `_apply_nba_context_adjustments` pipeline in `nba_agents.py` silently degrades to a no-op.
- **Impact:** NBA-02 ("System applies pace adjustment, back-to-back rest penalty, and opponent defensive rating weighting") is only functional when the caller manually constructs and injects NBAContextSignals.
- **Classification:** Architectural gap / tech debt. The code mechanism is correct and tested; it requires a data source (team schedule API, B2B detector) to complete the pipeline.

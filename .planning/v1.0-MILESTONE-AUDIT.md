## Critical Gaps

### Gap 1: QUANT-03 — stat_type routing not wired (HIGH)

**Requirement:** "System executes dynamic historical win-rate SQL queries parameterized by game context"

**What works:** `QueryBuilder` has three SQL templates (passing, rushing, receiving) and `ALLOWED_FILTER_KEYS` for full parameterization. `QuantParams.stat_type` is a validated Literal field.

**What's broken:** `make_quant_agent` at `src/sportsbet/graph/agents.py:101` hardcodes `stat_type="passing"` unconditionally. `stat_type` is not a field in `GraphState` TypedDict, so the Context Agent has no mechanism to override it. All `quant_analysis` invocations return passing yards true probability regardless of the market.

**Effect:** EV signals computed from passing yards distribution for a rushing yards bet are mathematically incorrect.

**Fix:** Add `stat_type: str | None` to `GraphState`, have `context_agent` write it, have `quant_agent` read `state.get("stat_type", "passing")`.

---

### Gap 2: QUANT-04 — games table population pipeline missing (HIGH)

**Requirement:** "System simulates historical signal performance via a backtesting module that replays past QuantResult signals against closing lines"

**What works:** `BacktestEngine`, `load_snapshots()`, `build_signals()` are fully implemented and tested with fixture data. Phase 24 added a NULL guard preventing TypeErrors.

**What's broken:** No `ingest_games_seasons()` function exists anywhere under `src/sportsbet/ingestion/`. `load_snapshots()` LEFT JOINs `games g ON o.game_id = g.game_id` to get `g.game_date`. With an empty `games` table, every `game_start_time` is NULL. The Phase 24 NULL guard skips every row. `BacktestEngine.run([])` returns `BacktestReport(sample_size=0, clv_mean=None, roi=None)` silently.

**Fix option A:** Add `ingest_games_seasons(pool, seasons)` that writes rows to `games` from `nflreadpy.import_schedules()`; call in `cli.py`.
**Fix option B:** Refactor `load_snapshots()` to derive `game_start_time` from `odds_snapshots.snapped_at` directly, eliminating the `games` JOIN dependency.

## Integration Check

**Connected exports:** 28 | **Orphaned exports:** 2 | **Broken E2E flows:** 3/7

### Critical Integration Gaps

#### Gap 1: PROP-01 — `write_player_prop_snapshot` completely unwired

- **Severity:** Critical (data never persisted)
- **Files:** `src/sportsbet/ingestion/prop_odds.py`, `src/sportsbet/ingestion/odds_poller.py`
- **Issue:** `OddsAPIPoller.fetch_player_props()` is defined and tested. `write_player_prop_snapshot()` is defined and tested. Neither is imported or called from any agent, graph node, or CLI in `src/`. The `player_prop_snapshots` table will be permanently empty in a running system.
- **Fix:** Wire `fetch_player_props → write_player_prop_snapshot` inside `make_context_agent` or a dedicated prop ingestion step.
- **Affects:** PROP-01

#### Gap 2: PROP-06 / NBA-02 — NBA prop arbitrage hardcoded to NFL state key

- **Severity:** Critical (NBA prop EVSignal always None)
- **File:** `src/sportsbet/graph/graph.py` line 397
- **Issue:** `create_graph_with_sqlite()` instantiates `prop_arbitrage_node = make_prop_arbitrage_agent(sport="nfl")`. When `nba_quant_agent` runs and writes `nba_prop_result`, the shared prop arbitrage node reads `state["prop_result"]` (returns None) → guard fires → `ev_signal=None`.
- **Fix (simplest):** Make `make_prop_arbitrage_agent` check both state keys and use whichever is non-None, removing the `sport` param entirely. Or pass `sport="nba"` for the NBA path.
- **Affects:** PROP-06, NBA-02, PROP-05 (downstream)

### Non-Critical Integration Notes

- **QUANT-02:** `remove_vig_power` (Pinnacle devig) implemented but never called. Only `remove_vig_multiplicative` used in production. Tech debt if Pinnacle accuracy was required.
- **INFRA-01:** `prop_filters` accessed via `state.get()` in `prop/agents.py:141` and `nba_agents.py:170` but not declared in `GraphState` TypedDict. Runtime safe; TypedDict contract violated.
- **ARBT-01:** Multi-call checkpoint pattern for NFL game E2E analysis undocumented. Requires 3 sequential `ainvoke` calls with same `thread_id`.

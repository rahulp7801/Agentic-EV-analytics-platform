## Known Technical Issues

### OpenBLAS Memory Error
- **Error:** `OpenBLAS error: Memory allocation still failed after 10 retries, giving up.`
- **Trigger:** Any Python process that imports `pandas`/`numpy` after the first ingestion run (memory fragmentation).
- **Workaround:** The 2025-26 ingestion eventually succeeded on its own (ran in background for ~1 hour). If it fails again, run in a fresh terminal with: `set OPENBLAS_NUM_THREADS=1` before the Python command.
- **Root cause:** Windows + OpenBLAS BLAS threading conflicts under memory pressure. Long-term fix: upgrade to numpy 2.x or use a Linux environment.

### `teammate_out` Filter Returns 0 Rows
- **File:** `src/sportsbet/prop/nba_query_builder.py` — `NBAQueryBuilder.build()`
- **Problem:** When `situational_params.teammate_out_signals` contains multiple players who are all regular starters, chaining 4 `NOT EXISTS` subqueries finds 0 historical games where ALL of them were simultaneously absent. Returns `insufficient_sample`.
- **Current behavior:** Falls back gracefully to `insufficient_sample`, no crash.
- **Fix needed:** Either (a) use the single most impactful absent teammate, or (b) fall back to season-aggregate path when conditional sample < MIN_CONDITIONAL_SAMPLE.

### `predict.py` Season Hardcoded
- `predict.py` still uses `season=2024` and LeBron/LAL vs BKN. Update to `season=2025` for current-season analysis.

### `allowed_msgpack_modules` Warning
- `Deserializing unregistered type sportsbet.graph.models.ContextSignals from checkpoint` — LangGraph warning about checkpoint serialization. Non-breaking but will be blocked in a future LangGraph version. Fix: add `ContextSignals` to `allowed_msgpack_modules` in the checkpointer config.
